Chép file font Shelia (Việt hóa) vào thư mục này với MỘT trong các tên sau:
  Shelia.woff2  (tốt nhất)  |  Shelia.ttf  |  Shelia.otf
Trang sẽ tự dùng font này cho dòng "Nguyễn Minh Chí (Jayden)" ở trang đầu.
Chưa có file thì trang tạm dùng font Dancing Script (có hỗ trợ tiếng Việt).
Lưu ý: kiểm tra giấy phép của font trước khi đăng lên website công khai.
